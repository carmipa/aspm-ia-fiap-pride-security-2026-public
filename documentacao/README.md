## 🧱 Padrao de UX adotado

- Todos os arquivos possuem icones em titulos;
- Todos os arquivos possuem menu de navegacao cruzada;
- Shields sao usados para contexto rapido por pagina;
- Estrutura textual e mantida em blocos curtos para leitura escaneavel.
