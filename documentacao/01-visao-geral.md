## 📌 O que e o projeto

O ASPM IA FIAP e uma aplicacao CLI em Python para apoiar gestao de postura de seguranca, com estrutura modular para evolucao.

## 🎯 Problema que resolve

- Organizar funcionalidades de seguranca em um unico fluxo de uso.
- Criar base para cadastro, analise e auditoria.
- Facilitar evolucao para novos modulos (scanner e inteligencia aplicada).

## 👥 Publico alvo

- Alunos e equipe tecnica da FIAP.
- Usuarios que precisam de uma CLI simples para experimentar fluxos de seguranca.

## ✅ Escopo atual

- Menu principal CLI.
- Cadastro e listagem basica de usuarios.
- Tela Sobre com equipe e referencia do repositorio.
- Estrutura pronta para expansao.

## 🚀 Escopo futuro

- Scanner de vulnerabilidades.
- Persistencia com banco de dados.
- Melhorias de observabilidade e logs.
